# Ralph loops — v0.8 language and delight

## Loop 1 — Technical precision versus comprehension

**Finding:** Raw states such as needs_input are good protocol identifiers but poor interface language.

**Change:** Internal identifiers remain stable while a tested language layer provides plain labels and explanations.

## Loop 2 — Noun overload

**Finding:** Agent, session, familiar, provider, and subagent were being used interchangeably.

**Change:** Operational UI uses session, source, project, helper, place, and last update. Familiar remains the playful name for the visual character.

## Loop 3 — Useful status language

**Finding:** Some accurate labels were still abstract. “Investigating” and “preparing” required interpretation.

**Change:** The interface now says Researching and Getting started. Needs input becomes the more direct Needs you.

## Loop 4 — Fun without distraction

**Finding:** Location communicates the broad state, but the familiar could feel static after arrival.

**Change:** Small visual cues now reinforce work: a page while researching, sparks while editing, pulses while running, a check while testing, rest marks while waiting, and a parcel when finished.

## Loop 5 — Engagement without surveillance

**Rejected:** XP, speed scores, completion streaks, rankings, and mood penalties.

**Locked approach:** Delight comes from movement, environmental reaction, character animation, and satisfying completion—not pressure or performance judgment.

## Loop 6 — Honest summary language

**Finding:** “Working” was too narrow for a bucket that can include an open session waiting at the Campfire or recovering from trouble.

**Change:** The top-level count says Active. Needs you and Finished remain separate. Trouble and explicit disconnection provide calm next-step guidance without inventing urgency.
