# Ralph loops — v0.7 spatial grammar

The user reaffirmed that familiars moving to different locations is the product’s defining interaction. This pass makes that behavior a tested system rather than decoration.

## Loop 1 — Can the world be read without labels?

**Finding:** The strongest lifecycle states already had distinct destinations, but the spatial rule was implicit.

**Change:** Investigating, running, testing, needs-input, and finished states are now contract-tested to occupy distinct places.

## Loop 2 — Does every destination explain itself?

**Finding:** Internal node names such as bench_a and test_dungeon leaked into the inspector.

**Change:** A spatial model now supplies durable labels and meanings:

- Workbench — preparing or editing
- Archive — reading and searching
- Command Console — running commands or reporting trouble
- Test Dungeon — running checks
- Permission Gate — waiting for human input
- Shipping Dock — explicitly completed work
- Campfire — turn stopped and session idle
- Sleeping Nook — session ended

## Loop 3 — Is movement reported truthfully?

**Finding:** The inspector named a destination before the familiar physically arrived.

**Change:** It now says “Heading to…” while traveling and changes to the station name only on arrival. The registry reports arrival transitions so the interface updates immediately.

## Loop 4 — Can the behavior be appreciated?

**Finding:** The single-agent simulator advanced faster than Moss could reach distant stations.

**Change:** The tour now pauses long enough to show the route and arrival at each meaningful station.

## Loop 5 — Is interruption still safe?

**Finding:** Real agents can change state while walking.

**Locked behavior:** A new state routes the familiar back through its last authored waypoint before traveling to the new destination. It never teleports across structures.

## Locked spatial principle

Location is the primary status channel. Color, labels, pulses, and inspector text reinforce location; they do not replace it.
