# Ralph loops — v0.12 design system and living world

## Loop 1 — Which copy of the palette is the real one?

**Finding:** The palette existed three times: `palette/pnw-palette.json` for the
art pipeline, a `:root` block in `styles.css` for the interface, and a `signal`
object inside `renderer.js` for the canvas. All three agreed, but only by
coincidence — nothing would have caught the day one of them changed, and the
three used different names for the same colour (`attention` / `needs_input`,
`trouble` / `failure`).

**Change:** `src/design/tokens.js` is the source of record for every shared
value. The stylesheet keeps its literals so the first paint is correct without
JavaScript, `applyTokens()` rewrites them at boot so the module is what decides,
and `tests/design-tokens.test.js` fails if the JSON, the CSS or the canvas ever
disagree. A third assertion forbids colour literals in canvas code outright, so
the next colour cannot be invented in place.

## Loop 2 — Is the world alive or is it a screenshot?

**Finding:** The plate is beautiful and completely still. A monitoring tool that
never moves reads as stale even when it is current — the eye has nothing to tell
it the view is live. The campfire in particular is painted mid-flame and frozen.

**Change:** An ambient layer between the plate and the familiars. Cloud-filtered
light and an edge vignette grade the plate; low mist drifts across the clearing
on a one-minute cycle; the campfire gains a breathing glow, a flickering core on
the flame the plate already paints, and embers that rise and fade. The layer
draws no flame of its own — it draws the light that flame casts, so the
illustration stays the authority.

## Loop 3 — What may atmosphere cost?

**Finding:** Weather that tints a familiar or a tag has bought mood with
legibility, which is the one trade this product may never make. Ambient motion
could also be mistaken for agent activity, which would make the map lie.

**Change:** Everything ambient draws strictly under the placards and the
familiars, and a test asserts that ordering in the source so it cannot be undone
by accident. Cadences are an order of magnitude slower than any state animation:
mist crosses in about a minute, the fire breathes over 2.4 seconds, an attention
pulse is a quarter of a second. `prefers-reduced-motion` freezes the weather
without unlighting it. Measured cost is a flat 16.7ms frame — no jank.

## Loop 4 — A game next to a web page, or one instrument?

**Finding:** The canvas drew its placards and tags in a monospace HUD voice while
the panel beside it used web-card conventions — a rounded pill, sans-serif field
labels, a plain heading. Two languages for one product.

**Change:** One HUD language across both layers. Anything that *names* a field
rather than carrying its value wears the same treatment the canvas placards use:
mono, tracked, uppercase, muted. Values stay in the readable sans face. State
chips became square-cut with a hard 1px edge in the state colour. Section
headings carry a rule to the right edge. The viewport is framed by four corner
ticks rather than a border.

## Loop 5 — Which box is the live view?

**Finding:** The corner ticks were attached to `.world-frame`. On a wide screen
that is the map. On a phone the same element is a column holding the map *and*
the detail sheet below it, so the lower two brackets landed inside the sheet,
framing a paragraph of text. The first attempt also used a single
`clip-path: polygon()` for two opposite corners, which — being one closed path —
joined them into a continuous line along the top and bottom edges.

**Change:** The brackets are built from eight positioned gradients instead of a
clipped border, and they are worn by whichever box is actually the map: the
frame on a wide screen, the stage on a phone.

## Loop 6 — Was the weather worth it?

**Finding:** Mist, a cloud-filtered light grade and an edge vignette read as
atmosphere in a screenshot and as noise in a tool kept open all day. The plate is
already lit and already unmistakably Cascadian; the grade was dimming an
illustration that did not need help, and permanent drifting motion in the
periphery is exactly what a monitoring surface should not have.

**Change:** All three removed. Firelight is the only ambient effect left — the
one thing in the world that should obviously be alive, sitting where the eye
already goes. `AmbientLayer` lost two thirds of its code and the `ambient`
tokens lost eight values.

## Loop 7 — Two kinds of sign on one map

**Finding:** The world's own labels are made objects: a plank set into a darker
cedar batten, brass rivets at the corners, a soot edge, a shadow under it. The
labels the renderer added were translucent rounded rectangles with a hairline
border, and the detail panel was frosted glass — conventions from a medium that
is not this one, sitting a pixel away from hand-painted pixel art. The map
carried two kinds of sign and only one of them belonged.

**Change:** One recipe for every label, expressed as `sign` tokens and applied to
the familiar's tag, the station placards, the detail panel, the connect dialog
and the controls. A light parchment face was the more literal match to the
world's signboards and was rejected: four bright labels floating over a bright
map fought the familiars for attention. The plank is *stained* cedar instead —
warm enough to belong to the same wood, dark enough that five state colours stay
legible. The material changed; the contrast did not.

## Locked outcome

The world now has three layers with a rule each, and a test for each rule:

- **The plate** is the authority on what the place looks like.
- **Ambient** is firelight and nothing else. It may change how the world feels
  and never what it says; it draws under everything that carries meaning.
- **The HUD** — canvas and DOM alike — speaks one type language, and every colour
  in it comes from one file.

Ambient layout is deterministic, so the world is the same on every reload. A
signal colour still means exactly one thing, and decoration is forbidden from
borrowing one. Every label in the interface is now the same made object the
world builds its own signs from.
