# Ralph loops — v0.11 lifecycle-place simplification

## Loop 1 — One place or one place per session?

**Finding:** Four separate workbenches made session identity spatially stable, but every other lifecycle state already used a shared place. This multiplied scenery without improving the primary question: what is each agent doing now?

**Change:** The map now has one place per visible lifecycle stage. Up to four familiars share each place through stable, slightly staggered occupancy positions.

## Loop 2 — Why did Command overlap?

**Finding:** The map metadata described multiple occupancy points, but the runtime controller targeted one coordinate for every shared station and waypoint.

**Change:** Each session receives one stable slot. Wider offsets separate familiars at stations, smaller lane offsets keep them distinct while traveling, and edge clamping keeps name/state tags on the canvas.

## Loop 3 — Archive or research?

**Finding:** Archive looked like a place where old sessions were stored, even though it represented active read/search work.

**Change:** The place is named **Research** in the map, renderer, inspector, tests, and canonical docs. Bookshelves remain as its visual shorthand.

## Loop 4 — Campfire or bed?

**Finding:** Both communicated inactivity, but only one distinction helps the user. The Campfire means the agent finished its latest turn while the source session remains open. A bed meant the source session had ended, which is not actionable and kept stale characters on screen.

**Change:** The Sleeping Nook and sleeping/offline visual states are removed. `session_ended`, `disconnected`, and `reset` delete the session from the live registry and reconnect snapshot. The former bed area is neutral woodland scenery.

## Loop 5 — Labels as part of the interface

**Finding:** Only some stations had baked-in text, labels varied in wording and style, and generated lettering could not be treated as interface copy.

**Change:** The background plate contains no words. The renderer draws one uniform, exact label for all seven places: Workbench, Research, Command, Test, Idle, Needs Input, and Done.

## Locked outcome

The world now answers one question per visual layer:

- **Where is the familiar?** Broad lifecycle stage.
- **What does its tag say?** Exact current activity and identity.
- **Is it still present?** The source session still exists.

Finished work may remain at Shipping until the source session closes or its slot is needed. Ended sessions never linger.
