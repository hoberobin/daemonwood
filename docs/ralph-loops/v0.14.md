# Ralph loops — v0.14 both ends of the link

One question for the pass: *standing at the map, can I tell which terminal
that is, and where to go?* The terminal end already answered it — `npm run
connect` puts the familiar's name at the front of each session's status line.
The map end did not. Every finding below was checked on the running page,
with the author's own session, by screenshot.

## Loop 1 — The map hides the one word both ends share

**Finding:** The terminal says `Moss raccoon mechanic │`. The map showed a
raccoon with a glyph: the name only on hover, the terminal only after a
click, and then as the second row of a stats list under a row that said
nothing (see loop 3). With four familiars up, matching a window to a creature
meant knowing the species by heart.

**Change:** One module, `src/session-address.js`, is the map's end of the
link, and every place the page points at a session reads from it. The hover
nameplate gained a second line — `ttys003 · web-app` — under the name and
state, in its own case because `ttys003` is what `tty` prints and `TTYS003`
is not. The inspector leads with Terminal and Project.

## Loop 2 — The alert says who, never where

**Finding:** `Moss needs you` — then click, read the drawer, then go and
find ttys003. Three steps for the one question the alert exists to answer.
The next step under the familiar said "Switch back to that Claude Code
session", and *that* was the whole problem.

**Change:** `Moss needs you · VS Code ttys003 · web-app`, on the sign itself,
when one session is waiting (several would be a list, and the map is the
list). The next step reads `Answer it in VS Code ttys003 · web-app.`, and
`Check it in … when convenient.` for Trouble; a session the bridge could not
place gets "its Claude Code terminal" rather than a blank. A phone drops the
address from the alert for room and keeps it one tap away.

## Loop 3 — A Session row that reads as garbage

**Finding:** `SESSION the-patch-codex-starter-v0-10-ff` directly above
`PROJECT the-patch-codex-starter-v0.10`. Claude Code names every session;
without `/rename` the name is the project's slug plus two random characters
(`nameSource: "derived"`, or `"collision"` with a number when two sessions
share a project). The note said so and the bridge dropped that field. Claude
Code's own session list hides those names too (`nameSource!=="user"` in the
binary's own listing code).

**Change:** The bridge carries `sessionNameSource`. The Session row appears
only for a name somebody chose — `user`, `auto`, `hook`, `peer` — and not for
the two fallback kinds. A note from an older bridge that does not say is
given the benefit of the doubt.

## Loop 4 — "Connect" beside a familiar that plainly is

**Finding:** The top-right button said **Connect** whether or not anything
was connected. With a familiar on the map it read as "not yet". The page had
no way to say "yes": only `npm run status` could.

**Change:** `server.mjs` hands the bridge the installer's own check — the
twelve hooks in `~/.claude/settings.json` and the status line — and the
bridge reports it in `/api/health`, on the stream's first message and on
every beat, cached for fifteen seconds between reads. The button reads
**Claude Code connected** with a green dot or **Connect Claude Code** with an
amber one, and the dialog behind it gives the numbers. When hooks are
missing but sessions are on the map — discovery from the notes makes that
possible — the dialog says those sessions move only as their notes change. A
bridge handed no check (a test, an older `server.mjs`) shows the plain button.

## Loop 5 — A restart renamed everyone

**Finding:** Caught while screenshotting loop 4. The bridge was restarted on
the new code; the map came back from Claude Code's notes within two seconds,
as designed — and the author's session, Moss in the terminal's status line
since morning, was Nettle. `chooseFamiliar` hashed the session id into
whatever pool of species was free *at the time*, so the same session came
back as a different creature whenever the set of live sessions differed.
The status line would follow the map, so both ends agreed; the person who
had learned "Moss is this window" was the one left wrong.

**Change:** Two things. Every session now prefers one familiar for life,
fixed by its id, and walks to the next along the family only while its own is
worn by a live session. And the bridge remembers each session's face and
terminal app in `~/.the-patch/familiars.json` (two hundred entries, oldest
out, written whole through a rename), and consults it at admission before
choosing; a remembered face is still refused if a live session wears it. A
session discovered from its note also gets its terminal app back this way,
which it otherwise lacked until its next hook.

## Loop 6 — A session that blinks out

**Finding:** A `SessionEnd`, or a killed process, removed the familiar on the
same frame the event arrived. After a morning of watching a creature walk
between stations, the ending was the one move it did not get to make — and
with one session up, the "clearing is quiet" notice dropped over the map in
the same instant, so the ending was also invisible.

**Change:** The plate paints a chained gate between two lanterns at the foot
of the south path; that is now a node past the bottom of the picture, and
the only edge a path leaves by. On `session_ended` or `disconnected` the
registry moves the record out of the sessions and into a `departing` set:
still drawn, still hoverable, still followed by the inspector (which says
**Left** and why), but not counted, seated, listed or selectable. The
controller's `leave()` routes it through the ring and down the south path,
and state can no longer steer it. The badge becomes a waving hand in the
disconnected grey, rocking as it walks; over the last seventy units the whole
familiar fades, so it goes *through* the gate rather than being clipped by
the edge. The quiet-clearing notice waits for the last walker to be gone. A
clock ends any walk that somehow stalls. `superseded` (a `/clear` hand-over),
`unproven` and `reset` stay instant: the first because the same face carries
on in the same terminal, and a goodbye beside a hello is two of one creature;
the others because there was nothing real to wave to.

Verified live by ending the author's own session on the map (its process
proof in the event), photographing the turn, the walk and the fade, and
re-admitting it with a tool event: same face, same terminal.

## Rejected

- **A permanent name label on the map.** The v0.12 decision stands: the
  hover nameplate and the inspector name the familiar, and the address rides
  with them. A name at rest is the sign this design removed.
- **Showing the derived slug dimmed.** Dim garbage is still garbage.
- **Polling `/api/health` from the page for the install check.** The beat
  already exists; the check rides on it.
- **Persisting the whole snapshot to disk.** Still rejected (v0.13); the
  face is the one thing the notes cannot give back, so only the face is kept.
- **Fading in place for the goodbye.** Cheaper, but the map has a gate and a
  path drawn to it, and a familiar that dissolves where it stands is a
  crash, not a departure.
- **A door glyph for leaving.** Unambiguous at any size, but the user asked
  for something with a little fun in it, and a wave is a gesture where every
  other badge is a tool.

## Locked outcome

- Everywhere the page points at a session it names the terminal and project,
  in one wording, from one module.
- A Session row exists only for a name somebody chose.
- The top bar says whether Claude Code is connected, from the bridge's own
  check, within a beat of it changing.
- A session keeps its familiar for life. A bridge restart never renames one.
- A session that ends walks out through the gate, waving, and is watched all
  the way; the map never blinks a familiar away.

Verified live at the end of the pass: the alert read `Nettle needs you · VS
Code ttys001 · the-patch-codex-starter-v0.10` for a permission event posted
with the session's own process proof; the slug row was gone; the bar read
**Claude Code connected**; `~/.the-patch/familiars.json` held the session's
face after a restart; 145 tests pass.
