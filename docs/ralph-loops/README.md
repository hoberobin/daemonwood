# Ralph loops

The iteration log. One file per version: what was found, what changed, and —
just as important — what was rejected, so a bad idea does not get reintroduced
six weeks later because nobody wrote down why it lost.

Every loop asks the same question: does this change improve the core promise?
*In three seconds, can I tell whether my agents are okay and who needs me?*

These are history, not specification. Where a loop file and the current code
disagree, the code is right and the loop file records what was true at the time.
`v0.10` in particular describes a Codex adapter that has since been removed;
`../project-manifest.md` holds the decisions that are still in force.
