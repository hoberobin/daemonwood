# Concept references

These images preserve the visual exploration that established Daemonwood's Pacific Northwest mood, composition, materials, and character direction.

They are references—not runtime sprites, tilesets, or exact layout specifications. When a concept image conflicts with `../art-bible.md`, `assets/map/workshop.tmj`, or the palette files, the canonical production files win.

`concept-05.png` was the original runtime plate. The current production plate is `assets/map/workshop-plate-v3.png`; its simplified seven-place layout and the coordinates in `src/world-model.js` are authoritative.

`familiar-family-runtime-preview.png` is a capture of the ten-character family in the live scene, kept for silhouette and scale comparison.
